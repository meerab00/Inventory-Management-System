# Inventory Management System

## Subject
DBMS (Database Management System)

## Project Description
Inventory Management System is a database-based system used to manage products, suppliers, purchases, sales, and stock.

The system helps keep inventory records organized and makes it easier to check available stock and low-stock products.

## Main Features

- User and role management
- Product management
- Category management
- Supplier management
- Purchase management
- Sales management
- Stock management
- Low-stock report
- Inventory reports

## Database Tables

The main tables in the system are:

- Users
- Roles
- Products
- Categories
- Suppliers
- Purchases
- Purchase Items
- Sales
- Sale Items
- Stock Adjustments

## DBMS Concepts Used

This project uses important DBMS concepts such as:

- Primary Keys
- Foreign Keys
- NOT NULL constraints
- UNIQUE constraints
- CHECK constraints
- SQL queries
- Normalization
- Transactions
- Relational database design

## Technology Used

- PHP
- PostgreSQL
- pgAdmin 4
- HTML
- CSS
- JavaScript

## Database Management

The PostgreSQL database will be created and managed using pgAdmin 4.

The SQL database files in the `database` folder can be opened and executed using the PostgreSQL Query Tool in pgAdmin 4.

## Basic System Workflow

1. User opens the system.
2. Products and suppliers are managed.
3. Purchases are recorded.
4. Stock quantity is increased after purchases.
5. Sales are recorded.
6. Stock quantity is decreased after sales.
7. Low-stock products can be checked through reports.

## Project Scope

The current system focuses on basic inventory management.

The following features are outside the current scope:

- Online payment
- Payroll
- Accounting
- Delivery tracking
- Multi-branch management
- Mobile application

## Future Scope

The system can be improved in the future by adding:

- Advanced analytics
- Demand forecasting
- Mobile application
- Multi-branch inventory
- More detailed reports
